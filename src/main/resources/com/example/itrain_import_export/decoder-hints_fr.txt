#
# Vous pouvez modifier librement ce fichier. Il est d'abord cherche dans le
# repertoire de travail du programme, sinon la copie fournie est utilisee.
#
# Format :
#   **gras**            met un passage en valeur
#   "- " en debut       transforme la ligne en puce
#   ligne vide          commence un nouveau paragraphe
#   # en debut de ligne est un commentaire et n'est pas affiche

**Ce que fait cette fonction**

Les modeles de decodeur sont des tables de CV d'un type de decodeur.
Plutot que de saisir chaque CV a la main, vous appliquez un modele a une locomotive ou a un wagon - puis vous n'ajustez que ce qui differe sur votre vehicule.

Ces modeles ont ete tires des notices PDF des fabricants par un script. Leur contenu n'est donc pas garanti exact. Merci de le verifier !

**Les trois voies**

- **Charger un modele** : applique un modele enregistre au vehicule selectionne. Les valeurs de CV deja presentes sur le vehicule sont remplacees.
- **Ecrire un modele** : enregistre les valeurs de CV du vehicule selectionne comme nouveau modele, reutilisable ensuite sur d'autres vehicules.
- **Modifier la configuration** : ouvre la table des CV du vehicule pour changer, completer et supprimer directement des valeurs.

**Charger un modele** s'utilise quand vous voulez attribuer une table de CV precise a une locomotive, puis la confronter aux valeurs reelles dans iTrain, par la voie de programmation ou en POM.
**Ecrire un modele** s'utilise quand vous avez deja dote des decodeurs de configurations et de textes. Le modele est enregistre au format CSV.
Ce fichier CSV ne peut pas etre modifie, mais il peut circuler (courriel, etc.) et etre relu et attribue partout via ce programme d'import/export.
**Modifier la configuration** vous permet de retravailler vous-meme les modeles sur tous les points.
Les entrees peuvent etre rendues actives ou inactives, et le type comme les descriptions peuvent recevoir vos propres textes.
Deplacez-vous toujours d'une cellule a l'autre avec la touche TAB. Elle seule valide le texte.

**L'adresse numerique - ou toute autre valeur - reste votre affaire**

Un modele apporte les valeurs du type de decodeur, pas celles de votre vehicule. Verifiez **CV 1** (et **CV 17/18** en adresse longue) apres le chargement - sinon plusieurs locomotives rouleront sur la meme adresse.
Cela se corrige dans iTrain, une fois le fichier ouvert la-bas.
Il est conseille de relire integralement toutes les valeurs par la voie de programmation ou en POM et de les mettre a jour ainsi.

**Tous les decodeurs n'acceptent pas tous les modeles**

Ce qui compte, c'est le protocole inscrit sur le vehicule sous "decoder" :

- **DCC, FMZ, CTC, SX2** : tous les parametres sont repris.
- **SX1 et Selectrix** : seulement les cinq premiers parametres - le format n'en connait pas davantage.
- **Motorola, multiprotocole, analogique** : pas d'import ; il n'y a pas ici de CV au sens de ces modeles.

**Ce que le programme ne fait pas**

Il n'ecrit rien sur le decodeur. Il ne lit rien depuis le decodeur.
Seul le fichier iTrain est modifie ; programmer votre vehicule ou le relire reste l'affaire d'iTrain.

**Avant d'essayer**

Faites une copie de votre fichier de reseau. Le programme sauvegarde certes automatiquement avant chaque ouverture (Preferences -> Chemins), mais votre propre copie a un endroit que vous connaissez rassure davantage la premiere fois.
